# Independent dimensions, frozen before builder inspection

Source: KIT_README.md, briefs A/B, tools/openapi.json, public-test-set.json, examples. Written 2026-10-11, before opening builder/ or the prohibited reports.

The final explicitly permits different numbers, identity questions, outcome tables, calendars, raw multi-document bank material and API fields/allowed values. It fixes the seven tool names, maximum three products, model and 30-minute build limit. Changed tool names below are an additional stress test, not evidence of a defect within the guaranteed final contract.

| Dimension | Plausible movement | Our probes |
|---|---|---|
| Identity | order, count, challenge kind, per-question/global failure limit, refuse immediately vs explain, hint accounting | reverse kit order and two total failures; three custom challenges |
| Privacy/opening | bank/AI/recording language, neutral purpose, recipient ambiguity, relatives | exact opening, forbid SMS claim; no relative disclosure |
| Bands | thresholds, three or more rows, zero attempts, different deadline units | 3 rows, 0/1/2 attempts, 2/4/6 business days |
| Persuasion | initial ask counts or not; silence/questions vs refusal; first offer date; call vs product budget | explicit refusal only; first offer deadline |
| Floors | percentages, max/min, rounding, product-independent formulas | max(standard floor, half arrears), cents ceiling |
| Calendar | working weekdays, holidays, cutoff, inclusive counting, backwards holiday adjustment, week meaning | Tue–Sat, Friday holiday, 15:00 cutoff, preceding working day |
| Callback | horizon, windows, retries, known customer vs third party | next two working days, 09:15–12:45, no today |
| Escalation | immediate human, queues, consent, hardship auto/nonauto, dispute ends/continues | immediate human, dispute transfer with note |
| Outcomes | renamed codes, priorities, reason omission/required, mixed products | transfer notes and oldest-first order; custom codes |
| Notes | single vs multi, before transfer, text content, all products | every unresolved product including singleton |
| Required/forbidden speech | exact phrases, when spoken, unsupported claims | portal sentence only, no SMS |
| Products | order, grouping, per-product confirmation, deadlines | descending lateness, immediate individual recording |
| API | renamed fields, nested arrays/status, refs, request envelopes, enums | nested request+response, custom kinds/queues |
| Input/deliverable | txt, split memos, precedence, tables, contradictions, trace/cost/secrets | .txt plus overriding memo, contradictory appendix |

We cannot infer a population score from 8 deliberately adversarial customers. Report conditional costs, not fabricated estimates of hidden prevalence.
